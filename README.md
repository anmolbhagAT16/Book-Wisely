# BookWisely – Railway Delay Prediction

## Project Overview
BookWisely is a Machine Learning project focused on analyzing railway operational data and predicting train delays.

## Problem Statement
Train delays affect passengers, railway operations and scheduling. This project aims to analyze historical railway data and develop machine learning models to predict train delays.

## Objectives
- Understand railway operational data.
- Perform Exploratory Data Analysis (EDA).
- Clean and preprocess the dataset.
- Identify important factors affecting train delays.
- Develop and evaluate machine learning models.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Dataset
The project uses railway operational data stored in Parquet format.

Dataset location: `Data/raw/`

## Project Structure
See the project folders for datasets, notebooks, saved models and output files.

## Installation and Setup

1. Clone this repository.
2. Create a Python virtual environment.
3. Install dependencies using `requirements.txt`.
4. Open the Jupyter Notebook in VS Code.
5. Select the project virtual environment as the kernel.
